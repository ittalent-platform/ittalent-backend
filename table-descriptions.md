# Database Table Descriptions

This document provides a comprehensive description of all database collections/tables within the ITTalent platform, based on the codebase schemas and models.

| No | Table | Description |
| :---: | :--- | :--- |
| 1 | **`users`** | Stores user identities, profiles, role-based authorization attributes, and account lifecycle states.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique identifier of the user.<br>- `email` (string, unique, indexed): Primary email address used for authentication and communications.<br>- `username` (string, unique, indexed): Unique username handle for the user.<br>- `role` (string enum: `'user'`, `'admin'`, `'recruiter'`, `'enterprise_admin'`, `'applicant'`): Access control role determining platform permissions.<br>- `status` (string enum: `'active'`, `'inactive'`, `'invited'`, `'suspended'`, `'blocked'`): Current lifecycle state of the user account.<br>- `full_name` (string, optional): User's legal or display name.<br>- `phone` (string, optional): Contact phone number.<br>- `email_verified` (boolean): Flag indicating whether the user's primary email address has been verified.<br>- `auth_version` (number): Monotonic counter incremented to invalidate active JWTs and sessions upon security events.<br>- `version` (number): Concurrency control version token for profile updates.<br>- `admin_lock_version` (number): Concurrency counter for administrative lock/suspend actions.<br>- `identity_request_version` (number): Version tracker for sensitive identity-altering requests.<br>- `verification_started_at` (Date, optional): Timestamp when email verification was initiated.<br>- `enterprise_id` (FK, ObjectId, ref: `enterprises`, optional): Reference to the enterprise the user belongs to (for recruiters and enterprise admins).<br>- `status_updated_at` (Date, optional): Timestamp of the most recent status transition.<br>- `status_updated_by` (FK, ObjectId, ref: `users`, optional): Reference to the administrator or user who modified the account status.<br>- `status_reason` (string, optional): Administrative justification recorded for the current account status.<br>- `status_history` (Array of objects): Audit history of account status changes, where each entry contains `status`, `changed_at`, `changed_by` (FK, ObjectId, ref: `users`), and `reason`.<br>- `createdAt` (Date): Timestamp when the user record was created.<br>- `updatedAt` (Date): Timestamp when the user record was last modified. |
| 2 | **`accounts`** | Stores authentication credentials and identity provider linkages for user login.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique account record identifier.<br>- `user_id` (FK, ObjectId, ref: `users`): Reference to the associated user profile.<br>- `provider` (string enum: `'local'`, `'google'`): Authentication method used for login.<br>- `provider_account_id` (string, optional): External user identifier supplied by third-party OAuth providers.<br>- `password_hash` (string, optional): Hashed password for local email/password credentials (hidden from default queries).<br>- `createdAt` (Date): Timestamp when the credentials record was created.<br>- `updatedAt` (Date): Timestamp when the credentials record was last updated. |
| 3 | **`tokens`** | Manages temporary cryptographic tokens used for account verification and password reset workflows.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique token identifier.<br>- `user_id` (FK, ObjectId, ref: `users`): Reference to the target user account.<br>- `type` (string enum: `'email_verification'`, `'password_reset'`): Specific security purpose of the token.<br>- `token_hash` (string, indexed): One-way cryptographic hash of the raw token string.<br>- `status` (string enum: `'pending'`, `'used'`, `'revoked'`): Current lifecycle state of the token.<br>- `expires_at` (Date): Expiration timestamp governed by a MongoDB TTL index for automatic deletion.<br>- `consumed_at` (Date, optional): Timestamp when the token was successfully verified and redeemed.<br>- `createdAt` (Date): Timestamp when the token was generated.<br>- `updatedAt` (Date): Timestamp when the token was last modified. |
| 4 | **`user_invitations`** | Tracks invitations sent to onboard new users or invite existing users into enterprise teams.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique invitation record identifier.<br>- `target_user_id` (FK, ObjectId, ref: `users`): Reference to the recipient user account being invited.<br>- `invited_by` (FK, ObjectId, ref: `users`): Reference to the administrator or recruiter who issued the invitation.<br>- `kind` (string enum: `'new_account'`, `'enterprise_membership'`): Category of invitation (new account creation vs. enterprise team join).<br>- `role` (string enum: `'user'`, `'recruiter'`, `'enterprise_admin'`): Role to be assigned to the user upon accepting the invitation.<br>- `enterprise_id` (FK, ObjectId, ref: `enterprises`, optional): Reference to the enterprise the user is invited to join.<br>- `token_hash` (string, unique): Hashed invitation token included in the invitation link.<br>- `status` (string enum: `'pending'`, `'accepted'`, `'revoked'`, `'cancelled'`, `'expired'`): Current state of the invitation.<br>- `expires_at` (Date): Expiration timestamp of the invitation token.<br>- `accepted_at` (Date, optional): Timestamp when the recipient accepted the invitation.<br>- `revoked_at` (Date, optional): Timestamp when the invitation was cancelled or revoked.<br>- `delivery_status` (string enum: `'pending'`, `'sent'`, `'failed'`): Status of the invitation notification email delivery.<br>- `delivery_attempts` (number): Total count of email delivery attempts made.<br>- `createdAt` (Date): Timestamp when the invitation was created.<br>- `updatedAt` (Date): Timestamp when the invitation record was last updated. |
| 5 | **`user_email_changes`** | Manages multi-step verification and authorization for user email address modifications.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique email change request identifier.<br>- `target_user_id` (FK, ObjectId, ref: `users`): Reference to the user requesting the email change.<br>- `requested_by` (FK, ObjectId, ref: `users`): Reference to the user or administrator who initiated the change.<br>- `current_email` (string): Active email address of the user prior to confirmation.<br>- `new_email` (string): Requested new email address awaiting verification.<br>- `token_hash` (string, unique): Hashed verification token delivered to the new email address.<br>- `expected_version` (number): Concurrency control version required to ensure the profile was not mutated concurrently.<br>- `status` (string enum: `'pending'`, `'completed'`, `'revoked'`): Status of the email change workflow.<br>- `expires_at` (Date): Expiration timestamp of the verification token.<br>- `completed_at` (Date, optional): Timestamp when the email update was confirmed and applied.<br>- `createdAt` (Date): Timestamp when the request was initiated.<br>- `updatedAt` (Date): Timestamp when the request was last updated. |
| 6 | **`user_audits`** | Provides an append-only, immutable audit trail for all sensitive administrative and security actions on user accounts.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique audit log record identifier.<br>- `target_user_id` (FK, ObjectId, ref: `users`): Reference to the user account that was modified.<br>- `actor_user_id` (FK, ObjectId, ref: `users`): Reference to the user or administrator who performed the action.<br>- `action` (string enum: `'account_invited'`, `'profile_updated'`, `'role_changed'`, `'status_suspended'`, `'status_reopened'`, `'invitation_accepted'`, `'invitation_revoked'`, `'email_change_requested'`, `'email_changed'`): The specific action executed.<br>- `result` (string: `'success'`): Outcome of the logged action.<br>- `reason` (string, optional): Administrative rationale supplied for the change.<br>- `changes` (object, optional): Key-value diff of attributes before and after the modification.<br>- `version` (number): Version snapshot of the user record at the time of the event.<br>- `occurred_at` (Date): Exact timestamp when the action took place. |
| 7 | **`enterprises`** | Stores company profiles, business information, corporate settings, and organizational metadata.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique enterprise identifier.<br>- `name` (string, indexed): Commercial/brand name of the enterprise.<br>- `legal_name` (string, optional): Official registered legal company name.<br>- `tax_code` (string, unique): Government corporate tax registration number.<br>- `registration_number` (string, optional): Business incorporation license number.<br>- `founded_year` (number, optional): Year the enterprise was established.<br>- `email` (string, unique): Primary corporate contact email address.<br>- `phone` (string): Primary corporate contact telephone number.<br>- `website` (string, optional): Official corporate website URL.<br>- `industry` (string, indexed): Primary business industry domain.<br>- `sub_industries` (Array of strings, optional): Secondary industry specializations.<br>- `company_size` (string enum: `'1-10'`, `'11-50'`, `'51-200'`, `'201-500'`, `'501-1000'`, `'1000+'`): Employee headcount range.<br>- `company_type` (string enum: `'Product'`, `'Outsourcing'`, `'IT Service'`, `'Consulting'`, `'Agency'`, `'Hybrid'`, `'Other'`, optional): Company business operational model.<br>- `address` (object): Registered headquarters address containing `street`, `city`, `district`, `state_province`, `country`, and `postal_code`.<br>- `branches` (Array of address objects, optional): Additional office or branch locations.<br>- `logo_url` (string, optional): Storage URL of the company logo image.<br>- `cover_url` (string, optional): Storage URL of the company banner/cover image.<br>- `short_description` (string, optional): Brief promotional tagline or summary.<br>- `description` (string, optional): Detailed corporate profile and background.<br>- `culture_summary` (string, optional): Overview of company values and work environment.<br>- `benefits` (Array of strings, optional): Company-wide perks and employee benefits.<br>- `tech_stack` (Array of strings, optional): Technologies, frameworks, and programming languages used.<br>- `social_links` (object, optional): Links to corporate social media channels (`linkedin`, `facebook`, `github`, `twitter`).<br>- `working_days` (string, optional): Standard working hours and days description.<br>- `media_gallery` (Array of strings, optional): Gallery image URLs showcasing office spaces and team activities.<br>- `status` (string enum: `'pending'`, `'active'`, `'suspended'`, `'rejected'`, `'inactive'`, `'deleted'`): Operational and verification status of the enterprise.<br>- `status_reason` (string, optional): Administrative rationale for status changes.<br>- `status_updated_by` (FK, ObjectId, ref: `users`, optional): Administrator who last changed the enterprise status.<br>- `status_updated_at` (Date, optional): Timestamp of the last status change.<br>- `creator_account_id` (FK, ObjectId, ref: `users`): User account that originally registered the enterprise.<br>- `admin_mutation_version` (number): Concurrency control version token for administrative modifications.<br>- `is_deleted` (boolean): Soft-deletion flag indicating whether the company profile is inactive.<br>- `deleted_at` (Date, optional): Timestamp when the enterprise was soft-deleted.<br>- `deleted_by` (FK, ObjectId, ref: `users`, optional): Administrator who executed the soft-deletion.<br>- `createdAt` (Date): Timestamp when the enterprise profile was registered.<br>- `updatedAt` (Date): Timestamp when the enterprise profile was last updated. |
| 8 | **`enterprise_registrations`** | Manages self-service company registration submissions, legal document verification, and administrative review workflows.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique registration application identifier.<br>- `registration_code` (string, unique): Human-readable tracking code assigned to the registration dossier.<br>- `version` (number): Concurrency control version counter.<br>- `corporate_email` (string, indexed): Corporate domain email address submitted for ownership verification.<br>- `representative` (object): Contact person details containing `full_name`, `phone`, and `position`.<br>- `company_data` (object, optional): Draft enterprise profile payload submitted by the applicant (includes `name`, `legal_name`, `tax_code`, `registration_number`, `website`, `industry`, `sub_industries`, `company_size`, `company_type`, `founded_year`, `address`, `short_description`, `description`).<br>- `legal_documents` (Array of objects, optional): Uploaded legal verification files, each containing `document_type` (`'business_license'`, `'tax_certificate'`, `'power_of_attorney'`, `'id_card'`, `'other'`), `file_name`, `file_url`, `file_size`, and `uploaded_at`.<br>- `status` (string enum: `'draft'`, `'pending_verification'`, `'email_verified'`, `'pending_review'`, `'under_review'`, `'approved'`, `'rejected'`, `'revoked'`): Current lifecycle state of the registration request.<br>- `claim_locks` (object, optional): Concurrency anti-collision locks preventing duplicate pending reviews (`tax_code`, `corporate_email`, `locked_at`).<br>- `verification_token` (object, optional): Email ownership verification details (`token_hash`, `expires_at`, `verified_at`).<br>- `invitation_token` (object, optional): Initial admin onboarding invitation token details (`token_hash`, `expires_at`, `accepted_at`).<br>- `review` (object, optional): Administrative evaluation audit containing `reviewed_by` (FK, ObjectId, ref: `users`), `reviewed_at`, `decision` (`'approve'`, `'reject'`), `rejection_reason`, and `checklist` (`tax_code_verified`, `legal_representative_verified`, `documents_verified`).<br>- `created_enterprise_id` (FK, ObjectId, ref: `enterprises`, optional): Reference to the enterprise entity provisioned upon registration approval.<br>- `createdAt` (Date): Timestamp when the application dossier was created.<br>- `updatedAt` (Date): Timestamp when the application dossier was last updated. |
| 9 | **`job_postings`** | Stores recruitment job listings, position details, compensation parameters, and listing lifecycles.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique job posting identifier.<br>- `enterprise_id` (FK, ObjectId, ref: `enterprises`): Reference to the hiring company.<br>- `posted_by_user_id` (FK, ObjectId, ref: `users`): Reference to the recruiter who authored the job posting.<br>- `title` (string): Title of the job position.<br>- `slug` (string, unique, indexed): URL-friendly slug used for public posting routes.<br>- `location` (string, optional): Work location (e.g., city, office address, or remote indicator).<br>- `employment_type` (string, optional): Employment arrangement (e.g., Full-time, Part-time, Contract, Internship).<br>- `salary_min` (number, optional): Minimum monthly or annual compensation amount.<br>- `salary_max` (number, optional): Maximum monthly or annual compensation amount.<br>- `salary_negotiable` (boolean): Flag indicating whether compensation is negotiable during interview.<br>- `currency` (string): Currency code for salary values (default: `'VND'`).<br>- `level` (string, optional): Seniority level targeted (e.g., Junior, Middle, Senior, Lead).<br>- `description` (string, optional): Detailed job overview and core responsibilities.<br>- `requirements` (string, optional): Candidate qualifications, technical skills, and experience criteria.<br>- `benefits` (string, optional): Perks and compensation benefits specific to this job offer.<br>- `openings` (number, optional): Number of vacancies to be recruited.<br>- `status` (string enum: `'draft'`, `'published'`, `'closed'`, `'archived'`): Lifecycle publishing state of the job posting.<br>- `published_at` (Date, optional): Timestamp when the job posting became publicly visible.<br>- `closed_at` (Date, optional): Timestamp when the posting was closed to new applicants.<br>- `archived_at` (Date, optional): Timestamp when the posting was moved to archive.<br>- `expires_at` (Date, optional): Expiration date after which the listing automatically closes.<br>- `deleting` (boolean, optional): Concurrency lock flag set while a deletion is being checked to prevent incoming applications.<br>- `createdAt` (Date): Timestamp when the job posting was created.<br>- `updatedAt` (Date): Timestamp when the job posting was last modified. |
| 10 | **`job_posting_audit_events`** | Records historical audit logs for publishing actions, status transitions, edits, and deletions of job listings.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique audit event record identifier.<br>- `job_posting_id` (FK, ObjectId, ref: `job_postings`): Reference to the target job posting.<br>- `enterprise_id` (FK, ObjectId, ref: `enterprises`): Reference to the enterprise owning the job posting.<br>- `actor_user_id` (FK, ObjectId, ref: `users`): Reference to the recruiter or administrator who initiated the action.<br>- `action` (string enum: `'created'`, `'updated'`, `'published'`, `'closed'`, `'reopened'`, `'archived'`, `'deleted'`): Specific lifecycle operation performed.<br>- `result` (string: `'success'`): Outcome of the operation.<br>- `job_title` (string): Title of the job at the time of the action (retained even after job deletion).<br>- `changed_fields` (Array of strings, optional): List of property names altered during update actions.<br>- `createdAt` (Date): Timestamp when the audit event was logged. |
| 11 | **`documents`** | Stores candidate document files including resumes, CVs, and cover letters along with storage metadata.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique document identifier.<br>- `owner_id` (FK, ObjectId, ref: `users`): Reference to the candidate who owns the document.<br>- `type` (string enum: `'cv'`, `'cover_letter'`): Category of document uploaded.<br>- `file_url` (string): Accessible public or signed storage download URL.<br>- `storage_key` (string): Unique cloud object storage key/path (e.g., in S3 or local storage).<br>- `file_name` (string): Original file name as uploaded by the candidate.<br>- `mime_type` (string): MIME type of the uploaded file (e.g., `application/pdf`).<br>- `size` (number): File size in bytes.<br>- `is_default` (boolean): Flag designating this document as the candidate's default selection for fast applications.<br>- `deleted_at` (Date, optional): Soft-deletion timestamp (null if the file is active).<br>- `createdAt` (Date): Timestamp when the document was uploaded.<br>- `updatedAt` (Date): Timestamp when document metadata was last modified. |
| 12 | **`certificate_links`** | Manages external credential links, digital badges, and professional certifications owned by candidates.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique certificate link identifier.<br>- `owner_id` (FK, ObjectId, ref: `users`): Reference to the candidate owning the certificate.<br>- `name` (string): Title or name of the credential/certification.<br>- `url` (string): Online verification URL or digital certificate badge link.<br>- `issuer` (string, optional): Issuing authority or organization (e.g., AWS, Coursera, Google).<br>- `issued_date` (string, optional): Issuance date string.<br>- `expiry_date` (string, optional): Expiration date string if applicable.<br>- `version` (number): Concurrency tracking version counter.<br>- `status` (string enum: `'available'`): Availability status of the credential.<br>- `suggested` (boolean): Flag indicating whether this certificate is recommended for inclusion in job applications.<br>- `idempotency_key` (string, hidden): Idempotency key preventing duplicate API submissions.<br>- `request_hash` (string, hidden): Cryptographic hash of the creation request payload.<br>- `history` (Array of objects): Audit history of modifications, where each item contains `actor_id` (FK, ObjectId, ref: `users`), `action` (`'created'`, `'updated'`, `'suggestion_changed'`), `occurred_at`, `result`, and `version`.<br>- `createdAt` (Date): Timestamp when the certificate entry was created.<br>- `updatedAt` (Date): Timestamp when the certificate entry was last updated. |
| 13 | **`applications`** | Manages candidate job applications, recruitment stages, internal evaluation notes, and candidate status progression.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique application record identifier.<br>- `job_id` (FK, ObjectId, ref: `job_postings`): Reference to the job position being applied for.<br>- `applicant_id` (FK, ObjectId, ref: `users`): Reference to the candidate submitting the application.<br>- `cv_id` (FK, ObjectId, ref: `documents`): Reference to the CV/resume document submitted.<br>- `cover_letter_id` (FK, ObjectId, ref: `documents`, optional): Reference to an optional cover letter document.<br>- `message` (string, optional): Introduction or cover message addressed to the employer.<br>- `status` (string enum: `'submitted'`, `'under_review'`, `'interviewing'`, `'offered'`, `'hired'`, `'rejected'`, `'withdrawn'`, `'position_filled'`): Current status of the application in the hiring pipeline.<br>- `withdrawal_reason` (string, optional): Justification provided by the candidate when withdrawing their application.<br>- `reapplied_from` (FK, ObjectId, ref: `applications`, optional): Reference to a previous closed application record that this submission replaces.<br>- `reapplied_as` (FK, ObjectId, ref: `applications`, optional): Reference to a newer application record that superseded this one.<br>- `status_history` (Array of objects): Append-only log of recruitment status transitions, containing `status`, `changed_at`, `changed_by` (FK, ObjectId, ref: `users`), `actor_role`, `note`, `message_to_candidate`, and `rejection_reason`.<br>- `certificates` (Array of objects): Immutable point-in-time snapshot of certificate credentials submitted with the application, each containing `certificate_id` (FK, ObjectId, ref: `certificate_links`), `version`, `name`, `url`, `issuer`, `issued_date`, and `expiry_date`.<br>- `notes` (Array of objects): Internal evaluation notes recorded by recruiters, each containing `author_id` (FK, ObjectId, ref: `users`), `author_name`, `content`, and `created_at`.<br>- `createdAt` (Date): Timestamp when the application was submitted.<br>- `updatedAt` (Date): Timestamp when the application record was last modified. |
| 14 | **`interviews`** | Schedules and manages interview sessions, participants, meeting modalities, and candidate reschedule requests.<br><br>**Fields:**<br>- `_id` (PK, ObjectId): Unique interview session identifier.<br>- `enterprise_id` (FK, ObjectId, ref: `enterprises`): Reference to the hosting enterprise.<br>- `application_id` (FK, ObjectId, ref: `applications`): Reference to the candidate's job application.<br>- `job_id` (FK, ObjectId, ref: `job_postings`): Reference to the job posting being interviewed for.<br>- `applicant_id` (FK, ObjectId, ref: `users`): Reference to the candidate attending the interview.<br>- `interviewer_ids` (Array of FKs, ObjectId[], ref: `users`): References to recruiters and interviewers participating in the interview.<br>- `created_by` (FK, ObjectId, ref: `users`): Reference to the recruiter who scheduled the interview.<br>- `scheduled_at` (Date): Starting timestamp of the interview appointment.<br>- `ends_at` (Date): Calculated conclusion timestamp of the interview (`scheduled_at + duration_minutes`).<br>- `duration_minutes` (number): Planned duration of the interview in minutes.<br>- `mode` (string enum: `'online'`, `'onsite'`): Format/channel of the interview.<br>- `meeting_link` (string, optional): Video conference URL (e.g. Google Meet, Microsoft Teams, Zoom) for online interviews.<br>- `location` (string, optional): Physical address, office room, or campus location for onsite interviews.<br>- `notes` (string, optional): Internal recruiter instructions, agenda, or candidate interview guidance.<br>- `status` (string enum: `'scheduled'`, `'reschedule_requested'`, `'completed'`, `'cancelled'`, `'no_show'`): Current status of the interview session.<br>- `reschedule_request` (object, optional): Candidate reschedule request payload containing `proposed_time`, `reason`, and `requested_at`.<br>- `status_history` (Array of objects): Chronological log of interview status updates, containing `status`, `changed_at`, `changed_by` (FK, ObjectId, ref: `users`), and `note`.<br>- `createdAt` (Date): Timestamp when the interview was scheduled.<br>- `updatedAt` (Date): Timestamp when the interview record was last updated. |
